# Original research scripts

This folder preserves active Python source files from the former
`test_syntactic_complexity` directory. Files are kept under their original
relative paths for reference, including older versions of analyses that have
since been consolidated into the package.

Use the package modules and commands documented in the parent README for new
work. The archived scripts are not imported by the package and may retain
hard-coded paths, prototype behavior, or dependencies specific to the original
research environment.

The original non-source assets (datasets, generated results, notebooks, and
checkpoint/cache files) are kept in the adjacent
`test_syntactic_complexity_archive` directory and are not part of the package
or GitHub source publication.
